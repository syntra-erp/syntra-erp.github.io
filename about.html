Fusion Bulk Item Manager – Desktop ToolPython · PySide6 · Oracle Fusion REST API

A desktop application that safely bulk-deletes mistakenly created items from the Oracle Fusion Item Master, using Oracle's supported Delete Groups REST API (create group → add items → Check Constraints → Submit for Delete).

  • Accepts item codes or exact descriptions, typed or uploaded from Excel/CSV (drag & drop).
  • Validate Only mode runs Oracle's constraint checks and reports which items can or cannot be deleted, with Oracle's reason, before anything is removed.
  • Delete Items mode asks for confirmation, skips blocked items (used in POs, with transactions…), submits the group and confirms the items are really gone.
  • Secure sign-in: basic authentication with MFA push handling, or SSO via OAuth 2.0 (Authorization Code + PKCE). Passwords are never stored.
  • KPI dashboard, live console and results table; email notifications; locked per-environment configuration for administrators.
  • Per-machine license activation, Windows installer, and automated tests against a mock Fusion server.
