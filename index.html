Fusion Bulk Item Manager

Delete items created by mistake from the Item Master in bulk, through Oracle's Delete Groups REST API — with a safe Validate Only mode first.

  • Paste item codes or descriptions, or upload Excel / CSV
  • Validate Only and Deep check before anything is deleted
  • Clear results: deleted, blocked (with Oracle's reason) or pending
  • Export results to Excel

How it works

  1. 1

    Connect

    Enter your Fusion URL, user and password in Settings. Nothing is stored.

  2. 2

    Validate

    Paste or upload the items and run Validate Only to see what can be removed.

  3. 3

    Delete

    Type DELETE to confirm. Follow every item live, then export the results.
