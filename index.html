Fusion Bulk Item Manager

v1.0 · Windows · Python desktop app · Oracle Fusion Delete Groups REST API

Safely bulk-delete mistakenly created items from the Oracle Fusion Item Master — using Oracle's supported flow: create delete group → add items → Check Constraints → Submit for Delete.

Features
  • Item codes or exact descriptions, typed or uploaded from Excel/CSV (drag & drop)
  • Validate Only (default): runs everything up to Check Constraints — nothing is deleted
  • Delete Items: asks you to type DELETE, skips blocked items, submits and confirms removal
  • Basic sign-in with MFA push, or SSO via OAuth 2.0 (PKCE). Passwords are never saved
  • KPI cards, live console, results table and optional email notifications
How to start
  1. Download OIC-IT-DE-INT.exe and run it (no installation needed).
  2. If Windows shows “Windows protected your PC”, click More info → Run anyway.
  3. Copy the Machine ID the app shows and send it to request your activation key.
  4. Open Settings: Fusion URL (https://<pod>.fa.<dc>.oraclecloud.com), user and password.
  5. Always run Validate Only first.
FAQs
  • Which items can't be deleted? Items used in POs, with transactions, etc. — Oracle blocks them, and the app shows Oracle's reason.
  • What role does the Fusion user need? Privileges for Product Management deletion groups and reading items / inventory organizations.
  • Can one key activate two computers? No — each key works only on the machine it was issued for.
